# Practics:
## Hello Docker Project
This project contains a simple Dockerfile that, when built and run, outputs “Hello, Captain!” to the console.
### Project URL
This is a local Docker project from the [roadmap.sh,](https://roadmap.sh/projects/basic-dockerfile) You can find the project details here.

## Basic Dockerfile:
   - Create Dockerfile
   - Add FROM OS:version
   - Add CMD ["command" "argument"]
   - docker build . -t 'namefile':version
   - docker run 'namefile'
